## 🚀 Projects

### 🛡️ SentinelAI

**SentinelAI** is an AI-powered security analytics and threat detection platform.

It is designed to analyze security events, identify anomalous behavior, assign risk scores, and assist with security investigation.

**Core Pipeline:**

```text
Security Events
      ↓
Data Ingestion
      ↓
Data Processing
      ↓
Feature Engineering
      ↓
Anomaly Detection
      ↓
Risk Scoring
      ↓
Alert Generation
      ↓
AI Investigation
      ↓
Incident Report
```

**Status:** 🚧 In Development

📁 Project: [`SentinelAI`](./SentinelAI/)
